# BLACK SWAN

**過去の実際の為替相場を舞台にした、FX × 部隊運営 × オートバトルゲーム。**

世界が滅びる日まで、残り120日。

未来から過去へ送り込まれた「こよみ」として世界各地を巡り、「ブラックスワン」に対抗するための準備を進めます。

## PLAY

**[BLACK SWANをプレイする](https://sariasandayo.github.io/BLACK-SWAN/)**

ブラウザでそのままプレイできます。

## GAME

ゲーム開始時の日付はランダムです。

その日から120日後に訪れる「ドゥームズデイ」までに、ブラックスワンへ対抗する手段を整えてください。

プレイヤーは、

- 世界各地で探索し、「残滓」を倒す
- 仲間を集め、部隊を編成する
- 武器や弾薬、医薬品を準備する
- 敵を偵察し、戦闘に備える
- FXで資金を運用する
- 記憶や情報から相場の手がかりを探す
- 位相残晶を集め、対抗装置を建造する

といった行動を自由に選択できます。

移動、探索、訓練、情報収集など、さまざまな行動で時間が経過します。限られた120日を何に使うかが攻略の鍵です。

## FX

ゲーム内の為替相場には、過去の実際の為替データを使用しています。

取引できる通貨は以下の4種類です。

- USD/JPY
- EUR/JPY
- GBP/JPY
- AUD/JPY

FXでは、買い・売り、レバレッジ、スプレッド、必要証拠金、証拠金維持率、ロスカット、損切り、利確、スワップなどを扱います。

レバレッジ上限など、一部のルールはゲーム内の年代によって変化します。

未来から来たこよみには、これから起きる出来事について断片的な記憶があります。その記憶を信じてリスクを取るか、情報を集めながら慎重に取引するか、あるいはFXを使わず戦闘を中心に進めるかは、プレイヤー次第です。

## BATTLE

戦闘はリアルタイムのオートバトルです。

出撃前に、

- 部隊編成
- 前列 / 後列
- 武器
- 弾薬・特殊弾
- 医薬品
- 弾薬の使用方針
- 撤退ライン

などを設定します。

敵にはそれぞれ特徴があり、偵察によって編成を調べることで、より適切な準備ができるようになります。

現在の編成と装備から勝率をシミュレーションすることもできます。十分に準備して安全を取るか、時間や資金を優先して危険を受け入れるかを判断してください。

## WORLD

拠点となる東京と、世界各地の都市を移動します。

- 東京
- ニューヨーク
- ロンドン
- フランクフルト
- シドニー

都市ごとに通貨、物価、入手できる装備、敵の傾向などが異なります。

東京は情報収集、対抗装置の建造、決戦準備などを行う特別な拠点です。

## NEWS

画面には、現在のゲーム内日付に対応したニュースが流れます。

ニュースは主にウィキペディア日本語版の記事をもとに、ゲーム内の時点から見て不自然にならないよう整形しています。後世になって付けられた事件名や、その時点ではまだ分からなかった情報などは、可能な範囲で表示から除外・修正しています。

ニュースは攻略に必須の情報ではありません。過去の世界を歩いている感覚を補うための要素です。
